# 链路指标与压力基线

本轮只建立无故障、无备份的 ns-3.48 压力基线，不修改任务类别、计算模型或路由策略。
采用 `feature/link-metrics-pressure` 分支，小步本地验证；完成后 PR 合并，阶段 CI 一次。

用户确认本轮链路带宽提升到 **10 Gbps**，并更新平台默认值。压力配置显式使用
`10000000000 bit/s`；历史 2 Gbps 结果只作参考，不作为同配置性能比较。
历史故障验收中显式指定的 2 Gbps 保持不变。

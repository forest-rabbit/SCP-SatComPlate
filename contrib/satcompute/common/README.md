# common 模块

`common/` 只保存会被两个及以上业务模块共同使用、且不属于某个具体领域的 C++
基础设施。领域代码仍应放在 `topology/`、`routing/`、`task/`、`traffic/` 或
`metrics/` 中，避免把这里变成无边界的工具集合。

## 文件

| 文件 | 功能 |
|---|---|
| `time-conversion.h` | 声明统一的时间参数异常和秒到整数纳秒转换接口 |
| `time-conversion.cc` | 校验有限、非负和 `int64_t` 范围，并按最近纳秒取整 |

人工配置继续使用秒；只有组件边界调用该转换，再交给 ns-3 `Time` 或保存为整数
纳秒。这样可以避免入口、拓扑和指标模块各自实现不同的舍入与溢出规则。

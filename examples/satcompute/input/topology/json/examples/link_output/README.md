# link_output 时间序列格式

本目录保存甲方按绝对时间输出的完整拓扑快照。文件名必须使用：

```text
YYYY-MM-DD_HH-MM-SS.json
```

例如：

```text
2024-01-02_00-00-00.json
2024-01-02_00-01-00.json
```

文件可约每分钟生成一次，也允许存在时间间隔。程序按文件名中的完整日期时间排序，
自动从最早快照开始，并根据仿真时长选择时间窗口。

## 运行方式

在仓库根目录执行：

```bash
./waf --run "satcompute"
```

默认运行 110 秒。只指定其他仿真时长并关闭业务流：

```bash
./waf --run "satcompute --simulationDuration=300 --offeredload=0 \
  --outputDir=/tmp/link-output-smoke"
```

规则：

- 程序自动选择目录中时间最早的文件，并将其映射为仿真 `0s`；
- 只选择 `[最早快照, 最早快照 + 仿真时长]` 闭区间内的快照；
- 支持跨日、不连续分钟和最多一天约 1440 个文件；
- 内存仅保存时间与路径，每个 JSON 到对应仿真时间才读取；
- `simulationDuration` 同时是 ns-3 的停止时间；不写时默认 `110s`。
- 数据不在本目录时，通过 `--linkOutputDir=<目录>` 覆盖默认位置。

## 顶层数组

每个文件是一个 JSON 数组，可同时包含链路项和卫星簇项。

链路项：

```json
{
  "node1_id": 101,
  "node2_id": 102,
  "type": "sat",
  "delay": 32.648
}
```

卫星簇项：

```json
{
  "sat_id": 101,
  "clusterId": 0
}
```

## 字段与单位

```text
node1_id/node2_id  链路两端的外部节点编号
type               sat 或 feeder
delay              毫秒 ms，可带小数
hold_time          秒 s，仅 feeder 使用
sat_id             卫星外部节点编号
clusterId          0=未分簇；n≥1时表示内部簇n-1
```

现有 JsonTopo 支持的可选链路字段继续保留。甲方以后可在链路项中增加
`link_bandwidth`、`bandwidth_gbps`、`link_load_up` 或 `link_load_down`，
无需改变数组结构。

现有 `LinkInfo` 和 `TopologyNodeInfo` 的其他成员、默认值及 `has_*` 标记均继续保留，
不会因为当前样例字段少而删除。不同数据集可以在最早快照声明更多卫星，程序不会写死
24 星或 28 个总节点。

## 节点和地面站推导

- 最早快照中的全部 `sat_id` 构成卫星集合。
- feeder 链路必须恰好有一个端点属于卫星集合。
- feeder 的另一个端点作为地面站节点编号。
- 程序不根据编号大小判断节点类型。
- 地面站按节点 ID 数值升序排列，第一个作为内部簇 0 的簇首，第二个作为簇 1
  的簇首，以此类推。
- `clusterId=0` 的卫星不参与分簇；`clusterId=1` 加入内部簇 0，
  `clusterId=2` 加入内部簇 1，以此类推。
- 后续快照必须包含与最早快照相同的卫星集合，只能更新其 `clusterId` 等属性。
- 后续 feeder 只能引用最早快照已经推导出的地面站；运行中不动态创建节点。
- 每个后续文件都是完整链路快照，未出现的上一时刻链路会被断开。

当前 8 个样例从 `00-00-00` 到 `00-07-00`，每分钟一个。最早样例可推导出
24 颗卫星、4 个地面站和 52 条链路。四个地面站 `10000`～`10003`
分别作为内部簇 0～3 的簇首；最早快照中所有卫星均未分簇，
`00-05-00` 起卫星 602 的 `clusterId` 由 0 变为 1，因此加入内部簇 0。

## 数据质量要求

- 每个文件必须是合法 JSON。
- 同一文件中 `sat_id` 不能重复。
- 链路端点不能相同。
- feeder 不能连接两个卫星或两个非卫星节点。
- 正数 `clusterId` 映射出的内部簇必须存在对应顺序的地面站簇首。
- 日期和时间必须有效，不能用近似时间或非法日期代替。

生产解析器不会自动修补缺失逗号等 JSON 语法错误。
